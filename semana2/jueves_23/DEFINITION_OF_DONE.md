# Definition of done

## se considerara terminado si se cumplen todos los puntos

- [ ] El test se escribio antes que el codigo (ciclo TDD)
- [ ] El test es funcional (GREEN)
- [ ] El codigo fue mejorado (REFACTOR)
- [ ] Los codigos no marca error con `ruff check`
- [ ] El código no marca error de `mypy`
- [ ] La cobertura de código no baja del 80% (`pytest --cov`)
